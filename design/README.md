# Design files

| File | What it is |
|---|---|
| `direction-contract.md` | The chosen direction (Blue & White): thesis, palette and first-viewport contract |
| `design.json` | Design system sidecar: tonal ramps, motion, shadows, component snippets, rules |
| `tokens/tokens.css` | CSS custom properties used by every page |
| `tokens/theme.json` | The same tokens for a WordPress block theme |
| `logo/` | Vector logo family traced from the restaurant's mark: `lockup-color.svg`, `lockup-reverse.svg`, `lockup-mask.svg` (one-color, for CSS masks), `enso.svg`, `wordmark.svg`, plus `logo-original-from-toast-site.png` |
| `data/menu.json` | Every dish with description, price, raw/spicy flags and its Toast item link |

`PRODUCT.md` and `DESIGN.md` live at the repository root, where design tools look for them.
Compare the traced logo against the restaurant's original art files before any production use.
